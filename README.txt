特別区 建築史 QUEST（PWA版）

ファイル:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

使い方:
1. このフォルダ一式をHTTPSで公開してください。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン →「ホーム画面に追加」。
4. 以後はホーム画面のアイコンから起動できます。

保存されるもの:
- XP / レベル
- 苦手問題とミス回数
- 建築家図鑑
- 総回答数・正解数
- 最高得点・最高コンボ

注意:
- 保存先はブラウザのlocalStorageです。
- SafariのWebサイトデータ削除などで消える可能性があります。
- ホーム画面追加後はオフラインでも起動できるようservice workerを含めています。
